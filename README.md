# 瞬間英作文

日本語文を見て英語を声で答え、その場で正誤が分かる学習アプリです。

## 起動方法

Node.js が必要です。追加のパッケージのインストールは不要です。

1. `start.bat` をダブルクリックします。黒い画面が開きます。
2. `http://localhost:5173` が開きます。Chrome が入っていれば Chrome で開きます。
3. 使っている間は、黒い画面を開いたままにします。終わるときは、この画面を閉じます。

`http://localhost:5173` に接続できないときは、アプリが起動していません。`start.bat` をダブルクリックしてください。すでに起動している場合は、ブラウザだけが開きます。

コマンドで起動する場合は、次のとおりです。

```bash
npm start
```

`index.html` を直接開いても動きません。問題データの読み込みとマイクの利用に、`localhost` か HTTPS が必要なためです。

## 使い方

1. レベル、問題数、制限時間を選び、「始める」を押します。
2. 日本語文が出たら、マイクボタンを押して英語で答えます。話し終えると自動で判定します。
3. 正解なら模範解答を再生して次の問題へ進みます。
4. 惜しい場合と不正解の場合は、違う語を確認して「再挑戦」か「次へ」を選びます。

声が使えないときは「文字で答える」でキーボードから回答できます。

## 判定の仕組み

判定は [js/judge.js](js/judge.js) にまとめています。回答と正解例を次のようにそろえてから比べます。

- 小文字化と記号の除去
- 短縮形の展開(`I'm` → `I am`)
- 数字表記の統一(`500` → `five hundred`)
- 同音語の統一(`there` と `their` など)
- 音声認識の綴りの違いの統一(`to-morrow` → `tomorrow`、`who's` → `whose`)

認識候補は上位3件まで調べ、最も正解例に近い候補で判定します。

| 判定 | 条件 |
| --- | --- |
| 正解 | そろえた後の回答が、正解例のいずれかと一致 |
| 惜しい | 一致はしないが、類似度0.7以上 |
| 不正解 | 類似度0.7未満、無回答、または時間切れ |

類似度は「1 − 単語の編集距離 ÷ 正解例の語数」です。

## 学習記録

- 正解率と苦手な問題は、各問の初回の結果で記録します。再挑戦の結果は記録しません。
- 直近の結果が正解でない問題を「苦手な問題」として扱います。次に初回で正解すると外れます。
- 記録はブラウザの localStorage に保存します。ブラウザや端末をまたいでは共有されません。サイトデータを消すと記録も消えます。

## 今日の復習と文法マップ

問題ごとに習熟度の段階を持たせ、復習の予定日に正解するたびに、次の復習までの間隔を延ばします(間隔をあけた繰り返し)。計算は [js/review.js](js/review.js) にまとめています。

| 段階 | 状態 | 次の復習 |
| --- | --- | --- |
| 0 | 間違えた | 翌日 |
| 1 | 1回正解 | 1日後 |
| 2 | 2回続けて正解 | 3日後 |
| 3 | マスター | 7日後 |
| 4、5 | マスター後も正解 | 14日後、30日後 |

- 数えるのは各問の初回の回答だけです。答えを見た直後の再挑戦は数えません。
- 予定日より前に正解しても、段階は上がりません。マスターまでは最短で5日かかります。
- 間違えると段階0に戻ります。マスターした問題でも同じです。
- 「この回答を正解にする」を押すと、正解として記録し直します。
- ホーム画面の「今日の復習」には、予定日が来た問題が出ます。問題数の設定で、1回に出す数を絞れます。
- 文法マップは、105項目をレベルごとに並べ、各問の習熟度を色で表します。3問ともマスターした項目は「完成」です。項目を押すと、その3問を練習できます。
- 学習した日ごとの回答数も記録しています。日付は端末の時刻で、0時に切り替わります。

## 連続学習日数と実績

ホーム画面に、続けて学習した日数と直近7日の学習の有無を出します。計算は [js/streak.js](js/streak.js) にまとめています。

- 1問でも答えた日を、学習した日に数えます。
- 今日まだ学習していなくても、昨日まで続いていれば途切れません。今日中に学習すると1日増えます。
- 最長記録も出します。

実績は全部で20個あり、ホーム画面の「実績」から一覧を見られます。条件は [js/achievements.js](js/achievements.js) にまとめています。

| 種類 | 実績 |
| --- | --- |
| 回答 | 初めての正解、50・100・500・1000問に答える |
| 連続 | 3・7・30・100日続けて学習する(最長記録で判定) |
| マスター | 1・50・100問をマスターする |
| 文法マップ | 1項目の完成、小学校・中学校・高校の全項目の完成、105項目すべての完成 |
| その他 | 1日に30問答える、1回の学習で10問以上を全問正解する、今日の復習をすべて終える |

- 獲得すると画面の下に知らせを出し、結果の画面にも獲得した実績を並べます。
- まだ獲得していない実績は、目標までの進み具合を出します。
- これまでの記録で条件を満たしている実績は、ホーム画面を開いたときにまとめて獲得します。
- 一度獲得した実績は、記録が変わっても消えません。

## 答えるまでの速さ

問題が出てから話し始めるまでの時間を記録します。計算は [js/speed.js](js/speed.js) にまとめています。

- 時間は「問題が出てからマイクのボタンを押すまで」と「マイクが音を拾い始めてから話し始めるまで」の合計です。ボタンを押してからマイクの準備ができるまでの時間は、端末によって違うので含めません。
- 記録するのは、音声で答えて正解した初回の回答だけです。文字で答えた回答、再挑戦、マイクを押し直した回答、20秒を超えた回答は記録しません。「この回答を正解にする」で正解にした回答は記録します。
- 正解の画面に、話し始めるまでの時間と、同じ問題の前回の時間を出します。結果の画面には、その回の平均を出します。
- ホーム画面には、直近7日の平均、その前の7日との差、14日の推移を出します。推移の図は、下がるほど速いことを表します。
- 話し始めは、iPhone と iPad では録音の音量から、PC と Android ではブラウザの音声認識の通知から判断します。話し始めの通知が届かないブラウザでは記録しません。
- 習熟度の段階やマスターの条件には、速さを使っていません。

## 記録の保存

ホーム画面の下にある「記録の保存」から、学習記録を書き出したり読み込んだりできます。

- **書き出す:** 習熟度、学習した日、実績、答えるまでの速さも含め、記録を1つの JSON ファイルにします。iPhone では共有の画面から「"ファイル"に保存」を選びます。PC ではダウンロードします。テキストとしてコピーもできます。
- **読み込む:** 書き出したファイルを選ぶか、テキストを貼り付けます。置き換える前に、回答数などの内容を確認できます。読み込んだ記録は、今の記録と置き換わります。
- **ファイルの検証:** 読み込むファイルは中身を確かめ、使える値だけを取り出します。処理は [js/backup.js](js/backup.js) にまとめています。

iPhone の Safari は、Safari を使った日数で7日間サイトを操作しないと、保存したデータを消します([WebKit の説明](https://webkit.org/blog/10218/full-third-party-cookie-blocking-and-more/))。ホーム画面に追加したアプリは対象外とされているため、iPhone の Safari ではホーム画面への追加を案内します。

- ホーム画面のアプリは Safari とは別の場所に記録を保存するため、移るときは書き出しと読み込みで引き継ぎます。
- ホーム画面のアプリとして開いたときは、データを消されにくくするよう `navigator.storage.persist()` で申請します。

## 問題の追加方法

[data/questions.json](data/questions.json) に次の形式で追加します。

```json
{
  "id": "E-052",
  "level": 1,
  "pattern": "現在形",
  "ja": "私は毎朝コーヒーを飲みます。",
  "answers": [
    "I drink coffee every morning.",
    "I have coffee every morning."
  ]
}
```

- `id` は重複しない値にします。
- `answers` には、正解として認める言い方をすべて書きます。短縮形の違いは書かなくても正解になります。
- 例文は、市販の教材から転載せず、新しく作ります。
- `level` は 1 が小学校、2 が中学校、3 が高校です。`id` の先頭はそれぞれ `E`、`J`、`H` にします。
- 問題数を変えた場合は、[tests/questions.test.js](tests/questions.test.js) の問題数も変更します。

収録している問題は、小学校、中学校、高等学校の学習指導要領解説(外国語編)の文法項目を細目で105項目に整理し、1項目につき3問の計315問としています。例文はすべて新しく作ったものです。

追加した文の音声ファイルは、次の手順で作ります。すでにあるファイルは作り直しません。

```bash
npm install --no-save --no-package-lock kokoro-js @breezystack/lamejs
```

```bash
node tools/generate-audio.mjs
```

音声ファイルがない文は、ブラウザの音声合成で読み上げます。

## 模範解答の音声

模範解答は `audio/` の音声ファイルを再生します。iOS 27 の iPhone の実機では、ブラウザの音声合成は処理が進んでも音が出ないことがありましたが、音声ファイルの再生は録音の直後でも音が出たためです。

音声は [Kokoro-82M](https://huggingface.co/onnx-community/Kokoro-82M-v1.0-ONNX)(Apache-2.0)で作りました。

## 対応ブラウザ

対象は PC の Chrome です。音声認識に対応していないブラウザでは、自動で文字入力に切り替わります。

PC と Android のブラウザでは、音声認識のために音声が提供元のサーバーへ送られることがあります。このアプリ自身は音声を保存しません。

## スマートフォンで使うには

スマートフォンのマイクを使うには、アプリを HTTPS のサイトとして公開する必要があります。`localhost` はその端末自身を指すため、PC で起動したアプリをスマートフォンから声で使うことはできません。

このアプリは静的なファイルだけで動くため、`index.html`、`css`、`js`、`data` を静的サイトのホスティングサービスに置けば公開できます。

### iPhone と iPad で動きが違う点

iOS 27 の Safari は、ブラウザの音声認識が2回目以降に音を受け取らなくなります([WebKit bug 321436](https://bugs.webkit.org/show_bug.cgi?id=321436))。実機の診断では、間隔をあける、先にマイクを開く、読み上げを挟むなどの回避策はいずれも効きませんでした。そのため、iPhone と iPad ではこのアプリがマイクを録音し、端末の中で文字に変換します。

- 音声は端末の外へ送りません。
- 学習を始めるときに音声認識モデル(Moonshine base、約70MB)を読み込みます。初回はダウンロードが必要で、以後はブラウザのキャッシュから読み込みます。
- ライブラリは jsDelivr、モデルは Hugging Face から取得します。どちらにも音声は送りません。
- 話している間は、そこまでの音声を繰り返し変換して途中の文字を表示します。端末の処理が終わるのを待って次を始めるので、更新の間隔は端末の速さで変わります。途中の文字は後から変わることがあります。
- 話し終えてから約1.2秒で録音を止め、全体を変換し直した結果で判定します。
- 音声認識モデルは、話し声があっても何も書かずに終えることがあります(模範解答の音声では1〜3%)。そのため、最初の1語は必ず書かせています。
- 書き出す語の数には、同じ語を繰り返し続けないよう、音声1秒あたり6語に8語を足した上限を設けています。
- 録音の最初の音がすでに話し声でも、話し始めを見逃さないようにしています。周囲の音の大きさは、最初の音が大きくても上限の値から見積もり始めます。

声の入力が動かないときは、「文字で入力」を押してキーボードのマイクを使えます。英語のキーボードに切り替えてから話してください。

認識に失敗したときは、「詳細」を開くと調査用の情報を確認して、コピーできます。

## 既知の制限

- 発音は評価しません。認識された文字列だけで判定します。
- iPhone と iPad の端末内の音声認識は、日本語のなまりが強い英語が苦手です。日本語の音声合成で読ませた英文では、12文のうち1文しか正しく認識しませんでした。端末内で動くほかのモデル(Whisper base)でも改善しませんでした。
- iPhone と iPad の端末内の音声認識は、日本の地名などの固有名詞が苦手です。`Kyoto` は `Cayotto` のように認識されることがあるため、例文では聞き取れることを確認した語を使っています。問題を追加するときも同じ点に注意してください。
- 音声認識が文法を補って聞き取った場合、文法の誤りが正解になることがあります。
- 登録していない言い換えは、正しい英文でも惜しいか不正解になります。納得できないときは「この回答を正解にする」で追加できます。追加した正解例は、そのブラウザの中だけで有効です。
- 同音語は同じ語として扱うため、文字入力でも `there` と `their` の違いは不正解になりません。
- `'d` は常に `would` として扱います。`had` の短縮形として使った場合は、正解例と一致しないことがあります。
